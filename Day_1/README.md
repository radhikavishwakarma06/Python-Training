# Python Training – Tasks 1 to 5

## 1. Project Overview

This repository contains Python programming tasks completed as part of my Python developer training. The objective is to strengthen Python fundamentals, logical thinking, problem-solving and programming skills.

## 2. Tasks Completed

| Task   | Topic                     | Concepts Covered                                                         |
| ------ | ------------------------- | ------------------------------------------------------------------------ |
| Task 1 | Python Basics             | Variables, data types, input/output, operators                           |
| Task 2 | Conditions and Loops      | If-else, for loop, while loop, break, continue                           |
| Task 3 | Strings                   | String methods, slicing, manipulation                                    |
| Task 4 | Collections               | Lists, tuples, sets, dictionaries                                        |
| Task 5 | Student Management System | Functions, dictionaries, validation, CRUD operations, JSON file handling |

## 5. Setup Instructions

### Prerequisites

* Python 3 installed
* Visual Studio Code installed
* Git installed

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the project folder

```bash
cd Python-Training
```

### Step 3: Verify Python installation

```bash
python --version
```

## 6. Run Instructions

Run each program separately using the following commands:

**Task 1 – Python Basics**

```bash
python task_1_basics.py
```

**Task 2 – Conditions and Loops**

```bash
python task_2_conditions_loops.py
```

**Task 3 – Strings**

```bash
python task_3_strings.py
```

**Task 4 – Collections**

```bash
python task_4_collections.py
```

**Task 5 – Student Management System**

```bash
python task_5_student_manager.py
```

Note: Run the commands from the project directory. Python 3 may also be invoked using `py` instead of `python` on Windows.
